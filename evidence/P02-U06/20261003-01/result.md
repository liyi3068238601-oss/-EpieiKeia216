## Implementation and boundaries

Added one fixed owned-artifact-integrity/v1 report under packages/application/evidence/. Its public functions are runOwnedNode, createLocalEvidenceReader, and buildEvidenceReport. runOwnedNode starts one Node script without a shell, requires that script to be tracked and byte-identical to its Git HEAD blob, and records the frozen expected revision, actual launch revision, process status/exit, and stdout/stderr byte counts and hashes. It never returns argv or raw logs; the fixed profile does not claim to verify a complete dynamic dependency closure.

The local reader binds the originating repository, the owned artifact root, the accepted EventStore, and a coordinator-fixed event source. The builder reads all matching U03 operation facts and observation pages with a bounded page count; it accepts only a committed operation_receipt with exact event/payload operation ID, full session/turn/run/task scope, attempt, tool call ID, profile result, process/run identity, artifact locator/size/SHA, and source revision. It separately calls U05 queryReceipt({source,eventId}) and checks the writer receipt's first sequence and canonical hash against the actual read fact. A queued admission is never used as an input to business result.

The owned artifact reader rejects path escape and links, rejects non-regular files and files above 8 MiB, reads at most the initial size plus one byte, compares opened-file and path identity/size/times before and after the read, and hashes the actual bytes. EvidenceReport separates process execution from the fixed mechanical profileResult and carries the exact scope/attempt/operation/tool-call IDs for downstream turn scoping. It contains no reply text, stdout/stderr content, keys, or hidden reasoning. The profile establishes artifact/effect/source integrity only; it does not claim arbitrary business semantics passed. The source decision is recorded in source-decision.md.

Changed paths are limited to packages/application/evidence/, tools/run-tests.mjs, and evidence/P02-U06/20261003-01/. No production runtime, model, external service, or dependency install was involved.
