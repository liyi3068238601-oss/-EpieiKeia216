# U09 source and implementation decision

Baseline 99c8702a34660f36b528efa0cca8c7257e6f98a5 independently accepts U08. Reuse accepted U03 projectAttempt/event canonicalization, U05 read-only paging/receipt validation and optional exact-bound U06 EvidenceReport. Existing source investigations and api-final-02.md/coordinator-final.md were checked against actual APIs before implementation. The earlier draft's P01 projection/U04 host inputs and private HMAC configuration are superseded: those objects do not prove all run/task/attempt associations, and a single report salt is sufficient for this local opaque-reference export. No third-party code or dependencies are copied/installed.

Public input is the target four-field bound scope, attemptId, readonly EventStore read/readObservations/queryReceipt and optional U06 reports. All supplied reports must match scope/attempt exactly; any mismatch rejects the association. Read streams with complete advancing pages and the existing conservative 32x256 cap. Include only exact-target events/observations and persistence receipt results. Partial/stalled/corrupt reads must remain explicit and cannot imply a sealed turn. Derive lifecycle from actual U03 committed writer order, never from caller-supplied P01 projection. Do not invent P01 evidenceStatus/toolReceipts or associated host status.

Construct output fields individually with closed enums/codes and finite numeric values. One private random per-report salt with domain-separated SHA-256 makes scope/event/observation/source/material/output refs joinable within the report and different across reports. No resolver/key configuration/raw export/policy DSL. Omit all raw scope IDs, paths/locators, argv/cwd/environment, exception text, input/reply/tool results, hidden reasoning and unrelated memory/Life content. Only the fixed accepted native source pin and recovery adapter version may be direct version identifiers; unknown source pins become refs. This report format serves local diagnostics and export.

The U05 reader validates masked stored capture material. Expose a snapshot digest/ref and byte summary, distinguish the historical raw digest/byte count from current validation. Current original-source validation remains NOT_VERIFIED; do not reopen or reconstruct a deleted temporary source. A persistence receipt is not proof of arbitrary business truth. A found receipt outside a partial fact scan, or an unreadable receipt query, is unverified; incompleteness alone cannot imply a missing/invalid receipt. Match kind, operation, actual receipt payload status and tool-call identity before marking a scanned receipt verified. No memory/Dream/Life implementation exists in this unit.

Mapped scope: packages/diagnostics/; tsconfig.json adds source include; tools/run-tests.mjs adds unit selector and inventory; evidence/P02-U09/20261003-01/. Actual test mapping is packages/diagnostics/test/diagnostics.test.mjs. Preserve accepted U01-U08 and frozen P01, production profiles/data/keys and installed ZCode. Native/Desktop composition belongs to U10; paid model and release-package evidence are separate. This decision is not a test or acceptance claim.
