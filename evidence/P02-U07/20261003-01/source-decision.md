# U07 source decision

Reuse accepted U03 normalized immutable events, canonical JSON and writer-order first-terminal projection, and accepted U05 EventStore read/observation/append APIs. Accepted U02 already exercised the actual Node SQLite commit/ACK boundary. The task card references the pinned DeepSeek Harness protocol (639ed015397290b3745d163aafe02ffee4aa3f84, MIT) for operation intent/receipt separation; no upstream source was copied. No excluded role or asset material is used.

The local implementation adds four coordinator-internal functions: inspectOperation, executeOperationOnce, recordVerifiedReceipt and recoverAttempt. It adds no tables, replay scheduler, configurable policy registry, model call or external send. Logical operation ownership is session/task, independent of turn/run/attempt. New intents use deterministic operation identities and stable owner scope. Effect receipts retain the actual bound attempt scope. Known outcomes aggregate by status and canonical result, preserving the first receipt; unknown observations may later be reconciled by a trusted verified receipt. Contradictions require review.

Reads include committed facts and delivery/conflict observations, with a fixed complete-pagination bound. Read failure, nonadvancing pages or an exceeded bound are unavailable, never an absence permitting execution. Only the ACK of a newly committed intent permits dispatch. A COMMIT whose ACK is lost never dispatches even when rereading finds that intent. Callback failure after dispatch means unknown. A durable receipt reread decides known completion; an in-memory callback result alone cannot.

Recovery seals only an evidenced open attempt, then rereads writer order. Existing terminal events remain authoritative. Missing attempts remain absent. Cancellation does not undo an effect or erase a late receipt. The derived interrupted fact explicitly uses the first committed attempt event as its fact-time basis; actual restart discovery time is observation metadata. It does not claim to know a crash instant. Concurrent discoveries share canonical facts and preserve separate delivery observations.

U05 does not expose an observation query by source/event identity. Because a conflicting candidate can change operation ID or owner, the inspector scans all observations completely before filtering by operation and first-fact identities. Both fact and observation scans have a fixed 32 x 256-row bound. An oversized store requiring more observation pages yields unavailable/needsReview even for a smaller selected operation. This is a conservative current scale limit, not a claim that absence or known success can be proved from a truncated scan.

The caller supplies an already stable operation ID and a trusted effect adapter; this module cannot infer whether an arbitrary external system actually performed an effect and is not an authorization or sandbox layer.

Scope mapping: packages/application/recovery/, tools/run-tests.mjs (unit selector and all-unit inventory), evidence/P02-U07/20261003-01/. The immutable plan and frozen P00/P01/U01-U06 author trees remain unchanged. Tests are mapped to packages/application/recovery/test/recovery.test.mjs and an owned child fixture under that test directory. No dependency install is needed; the existing fixed Node 24.14.0 and TypeScript 6.0.2 are reused.

All effect fixtures are local, owned synthetic files. A child-process kill between an fsynced effect and its receipt is a process-fault demonstration, not proof of power-loss behavior, production sends, or arbitrary tool idempotence. P02-U10 actual Native/Desktop composition remains NOT_RUN in this unit.
