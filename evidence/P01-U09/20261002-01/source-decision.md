# U09 来源与采用

沿用已接受的 P01-U01 调查、U02 真实模型试验和 U03–U08 接口。本单元直接组合已有角色加载器、原生插件安装器、U06 Hook 回执门禁、U07 事件投影和 U08 配置/授权判断，不增加人格二次改写调用。

ZCode 固定源码 `29628c9acdb81b703bbd4080c207a0e7ce5e276e`（Apache-2.0）在本机只读加载。原生 ProviderRegistry、AiSdkModelAdapter、createZCodeApp、Read 和事件流负责真实执行；本项目只新增合成评测夹具及传输记录。网络检测脚本借鉴已有 `spikes/P01/desktop-guard.cjs` 的 Node 部分，修正当前 Node 对 socket 参数归一化后的数组调用形态；它是测试检测措施，不是操作系统沙箱。

Herta H02 的角色表达/事实边界设计已纳入前置调查，此处仅借鉴评审方法，不复制其角色素材。实际资产为用户批准的 Mofox 精简 v3；JSON 和 manifest 分别校验，不把原始 TOML 的来源哈希当作运行资产哈希。游戏角色背景的来源与发行限制沿用 U04；本单元不作原创 IP 或公开再分发权利声明。

Python 传输复用既有 `httpx` 环境、官方 HTTPS 路由、P01 计数账本和互斥锁。每次请求发送前落账；异常或未知外部结果停止矩阵，不自动重试。只将白名单公开响应字段交给子进程与证据文件；隐藏推理不留存。真实 Key 不进入 profile、子进程环境、命令行或 Git。
