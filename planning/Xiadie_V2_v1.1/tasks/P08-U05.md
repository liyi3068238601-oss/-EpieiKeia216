# P08-U05｜每写者工作树与资产锁

**产品版本：0.8.0｜文档：1.1｜类型：implementation｜状态：not_started**

公共规范：[执行书](../02_计划执行书.md)；阶段和范围：[计划书](../01_项目计划书.md)。

**前置单元：** P08-U04

**输入：** 任务owner和执行权限

**允许改动：** `packages/work/worktrees.ts`。路径为新项目的目标设计，不表示文件已存在；映射变化需记录。不得顺手改旧工程、上游参考树或用户全局设置。

**具体做法：**

1. 每独立写者独立worktree

2. DSH共享树只一写其他只读

3. blend等二进制使用独占副本提交

**代码/设计来源：** [T02][D05]。开工读取关联测试，优先使用现有接口；移植代码登记原始commit/许可/修改，不复制被排除角色素材。

**测试和故障分支：** 同文件冲突/failed脏树/双写资产

**通过标准：** 失败产物保留，worktree不是OS沙箱

**产物和证据：** `evidence/P08-U05/<attempt-id>/result.md`，附baseline、来源采用决定、diff、命令/cwd/exit code、真实输出或hash、风险及回滚。实现单元登记测试映射：`tests/units/P08-U05.test.ts（目标路径；开工按实际测试框架映射）`。

**回滚：** 独立提交优先revert，仅撤本单元改动；数据迁移先验证备份，失败工作树保留，未知外部效果先核查不盲重试。

**停止条件：** 前置未通过、上游接口不符、缺授权/资源、scope要扩大、事实/权限关键失败时保存最小复现并报告blocked；普通编译与实现细节自主排查。

**交接判定：** 作者仅提交ready_for_review；独立审查/集成后accepted。NOT_RUN、mock与真实产品测试严格区分。

**需求：** R02, R04, R07, R08, R15。

**关键实现细化：**

1. 调用Git前读取repo状态和worktree porcelain清单；为task/attempt建立专属分支与路径，从明确base_commit创建，已有目录或脏状态不得覆盖。所有写者有独立writer_id登记。

2. DSH组内只读研究/审查可并行共享快照；第二个写者必须申请新的worktree或等待唯一写者释放。共享schema/接口由一个Owner维护，其它任务只提交变更请求。

3. 对.blend等二进制记录输入hash和独占产物目录，在副本执行，集成时先验证原hash未变再替换。失配进入review冲突，不能后写覆盖先写。

4. 任务失败或lease过期保留工作树/分支和diff。清理必须经独立检查确认没有用户或待审产物，并且有明确授权；git worktree lock只防维护清理，不当文件写锁。
