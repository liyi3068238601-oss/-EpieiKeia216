# P07-U08｜取消与检查点重启

**产品版本：0.7.0｜文档：1.1｜类型：implementation｜状态：not_started**

公共规范：[执行书](../02_计划执行书.md)；阶段和范围：[计划书](../01_项目计划书.md)。

**前置单元：** P07-U07

**输入：** 进程映射和operation_id

**允许改动：** `packages/adapters/dsh/cancel.ts`。路径为新项目的目标设计，不表示文件已存在；映射变化需记录。不得顺手改旧工程、上游参考树或用户全局设置。

**具体做法：**

1. 终止owned进程树并记录确认

2. 无原生resume时新attempt读取checkpoint而非宣称native

3. 未知外部效果先查receipt

**代码/设计来源：** [D02][D05]。开工读取关联测试，优先使用现有接口；移植代码登记原始commit/许可/修改，不复制被排除角色素材。

**测试和故障分支：** 一个包取消不影响另包；外部提交后断线

**通过标准：** 关闭进程不等于撤销外部动作，不调用虚构cancel方法

**产物和证据：** `evidence/P07-U08/<attempt-id>/result.md`，附baseline、来源采用决定、diff、命令/cwd/exit code、真实输出或hash、风险及回滚。实现单元登记测试映射：`tests/units/P07-U08.test.ts（目标路径；开工按实际测试框架映射）`。

**回滚：** 独立提交优先revert，仅撤本单元改动；数据迁移先验证备份，失败工作树保留，未知外部效果先核查不盲重试。

**停止条件：** 前置未通过、上游接口不符、缺授权/资源、scope要扩大、事实/权限关键失败时保存最小复现并报告blocked；普通编译与实现细节自主排查。

**交接判定：** 作者仅提交ready_for_review；独立审查/集成后accepted。NOT_RUN、mock与真实产品测试严格区分。

**需求：** R02, R04, R14, R17。

**关键实现细化：**

1. Bridge保存work_package_id到owned进程树的映射。SDK无单session cancel时只终止该工作包专属runtime；先发支持的正常shutdown，再按受控超时终止owned子进程，不按进程名称全局杀。

2. 取消后的Result保留已生成产物、最后证据与unknown_effects。用户仍可审查部分成果；不能自动清空工作树或把外部生成队列全局interrupt。

3. 恢复创建新attempt，读取已授权checkpoint、base/head与产物hash。明确标checkpoint_restart，只有真实协议测试证明原会话可继续时才标native_resume。

4. 测试两个同时工作包，取消A必须保持B运行；A提交远端请求后断线应先查询operation_id/receipt，查不明则等待选择，不再次自动提交。
