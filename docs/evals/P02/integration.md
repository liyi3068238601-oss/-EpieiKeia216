The coordinator assigns run/task/attempt identities before a new admitted operation. Session/turn/event IDs, timestamp and sequence come from actual Native envelopes. Actual own plugin hook-start metadata and the exact authorized process request establish transcript correlation. The capture is a derived adapter event referencing that Native hook identity; it is not a fabricated Native event. Sources are `zcode.native/v1` and `xiadie.transcript/v1`, with historical source locator/hash/bytes and source pin. Only masked current UserPromptSubmit material is retained; raw prompts, replies, reasoning, tool IO, hook receipts/nonce and errors are excluded from the new ledger. A success terminal stores reply digest/size, so durable lifecycle recovery intentionally does not reconstruct an authoritative reply string.

Native outcome and durability outcome are separate. Saved requires actual writer completion plus read-back receipt, a committed terminal and the actual capture delivery. Swallowed event-subscriber errors, queue admission, idle state or reply text cannot establish Saved/business success. Failures remain fixed codes and failed/unknown/unavailable states. Source paths are historical; deletion does not make current original-source validation pass. Public diagnostic export is accepted U09; internal coordinator target IDs are not a public redacted export.

Close first stops admission, aborts its owned operation signal combined with the caller's signal, waits for admission/completion and tail capture, then closes Native/Host, unsubscribes and drains/closes the writer. Source investigation found Native close does not wait for its foreground call before closing session resources, hence it is not used as that barrier. Restart recovers only evidenced attempts and inspects stable owned effect intents; unknown/conflicting/unavailable effect history blocks resume pending review and is never automatically replayed. Native read-only tools plus a separate owned fsynced effect fixture do not establish arbitrary Native write/send/generation idempotence.
