# Xiadie 1.0.0 产品需求与验收标准

状态：ready_for_review（作者稿）。产品目标版本为 1.0.0；需求基线为归档计划包 Xiadie_V2_v1.1 中的 requirements.json、01_项目计划书.md 与 04_需求追踪矩阵.md。计划包文档版本 1.1 不代表产品版本 1.1。

## 版本与状态解释

归档 requirements.json 的 28 项优先级均为 Must，原始状态均为 not_started，且只包含 id、title、stages、tasks、status、priority，并未逐项指定 targetVersion 或验收句。这里将每项 Must 映射到最终产品 1.0.0，是依据计划书最终范围、P15 发布候选和 P16 正式冻结门槛所作的执行映射推导，不是对原始 JSON 字段的转述。各项 stages 是过程里程碑：P00 为 0.0.0，P01 至 P14 对应 0.1.0 至 0.14.0，P15 为 1.0.0-rc.1，P16 为 1.0.0。逐项 task 数组和原始字段完整保存在本文附录。

下表的“可核验标准”定义未来验收所需的可观察结果，不表示实现、测试或验收已经完成。每个需求须在其映射任务留下证据，并在 P15 核验最终 Must 覆盖；未解决的关键问题阻止发布候选冻结。P16 只有在所有 Must 已验收、无阻断问题且获得发布授权后才能通过。模拟测试、SDK 初始化、开发目录运行或单个正常样本不能替代计划要求的真实产品及 Windows 发行包证据。

## 外部资源与发布阻断条件

原创角色设定、模型、代码、Live2D SDK 与模型资源、语音和其他分发资产分别核对来源、许可范围、署名与再分发权。Live2D SDK 的可用条件不能替代角色模型的资产许可。若任一进入发行包的资源授权未知、不可再分发或与目标渠道不兼容，必须替换为可授权资源或阻断发布；不得把许可未知写成已获许可。替代资源需重新绑定哈希并复核最终包。
