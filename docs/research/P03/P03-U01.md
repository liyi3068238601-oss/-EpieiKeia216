## 结论与候选默认路线

候选默认路线是：由 Xiadie 在每个已串行准入的 turn 提供一个受信、限量的 memory data provider；先在 U02 以真实 Native 调用验证公开 MemoryService 能否满足所需数据契约。当前代码在 host admission/preflight 每 turn 创建 ContextPacket，但 XiadieHostOptions 没有受信 memory reader/provider，P02 memoryCandidates 只进入诊断，P01 factory 仍禁用 Native memory。Native 自身 context 初始化缓存 MEMORY.md，context refresh 复用缓存。因此启动时开 Native memory 或传诊断候选都不能证明逐 turn 的 selected-source freshness。需要验证更小的公开 seam；只有当 U02 证实 provider/API 缺口且实际 Native 请求边界必须获得原始字节和 source hash 时，才把有界、只读 raw-byte adapter 作为候选默认实现。若不能验证真实请求路径、读权限与错误状态，暂停实现并记录 gap；这里不批准生产代码。

身份候选是应用侧 UUID registry 与 Native canonical root/legacy alias 分开管理，借助 Git common-dir/worktree identity 与显式 ownership/import 规则；不把身份写入真实仓库 Git config。创建 UUID root、重新计算 key 或把旧路径文本当 workspaceIdentity 都不能证明旧 Native 知识不存在，也不授权迁移、合并或双写。旧 key 的查找、linked worktree、copy/fork、目录实际移动与数据根搬迁须在 U02/U03 的自有 fixture 中分别验证。

解析候选是在不新增依赖的前提下，先验证固定 Native 包的 Marked Lexer 与 YAML parseDocument 是否能被当前 Xiadie 集成边界合法、稳定地使用；如果不能，再论证最小依赖引入。任何路径均先严格解码原始 UTF-8、保留原 topic frontmatter、限制字节与 YAML aliases、保留解析错误；只读 MEMORY index 和明确选中的 topic，不递归扫描历史。Marked 应用 Lexer/token 结构处理 HTML comment 与链接关系，不用正则删除 Markdown 注释。不要继承 Native recall 对损坏 frontmatter 折叠为空结果、递归扫描，或 context 对读取错误折叠为缺失的行为。

只读 reviewer 候选默认是 memory profile 关闭，并在最终 tool projection/registry/executor 层暴露精确只读 allowlist，不注册 Write/Edit、Bash、MCP、plugin、Node REPL 等写或旁路工具。由宿主在模型执行外保存 review output。若原生 profile 已含写工具，关闭 memory 并不会删除它们；prompt 和 Plan mode 也不是执行边界。固定 Native PermissionService 匹配未经规范化的 file_path，而 Write/Edit handler 之后才 normalize/resolve，并不限制 workspaceRoot 外路径；静态反例 E:\review-out\..\repo\shared.ts 可先匹配 E:\review-out\* 再解析进 shared.ts。文件系统 adapter 也没有授权 root containment 参数。此为源码静态推导，未运行探针；所以结果目录 glob 不能当 sandbox。U02 需以最终工具注册和执行器及 traversal/symlink fixture 证明拒写；若固定 Native 能力不足，应先记录最小隔离缺口。

ADR/交接候选采用项目本地静态模板加窄的证据字段校验器。MADR 4.0.0 的模板为 MIT OR CC0-1.0，可选择所需的最小字段，无运行时工具安装成本；本地 v1.1 handoff 模板也是清楚的人读骨架，但本身不验证权限、source hashes 或接受门槛。Native Agent task 生命周期可用于记录执行证据，completed 不等同于独立 accepted，也不绑定 P03 的项目路径、基线、输入来源与评审证据。adr-tools 的工具是 GPL-3.0-or-later，而其 LICENSE.txt 将工具写入项目的内容另标 CC BY 4.0；其 Bash/POSIX 安装负担不适合作为本阶段默认依赖。以上仅供 U02 采纳决策，不在本任务建立 ADR。
